# esp32-stepper-driver
ESP32 기반 커스텀 스테퍼 모터 드라이버 설계 및 학습 기록
ESP32 Stepper Driver

프로젝트 목표

ESP32를 중앙 제어기로 사용하고, 4개의 외부 모터 전력 구동 회로를 제어하는 커스텀 스테퍼 모터 드라이버를 설계한다.

목표 구조

- 중앙 제어기: ESP32
- 모터 구동부: 모터별 MOSFET H-브리지 4개
- 전류 감지: 션트 저항과 전류 감지 회로
- 제어 목표: 마이크로스테핑, 전류 제어, 향후 센서리스 호밍 연구
- 활용 대상: EasyThreed K10 3D 프린터

학습 기록

1. 전류 감지 회로

- 션트 저항을 이용해 전류를 측정한다.
- 전류 감지 증폭기가 작은 전압 차이를 증폭한다.
- ESP32의 ADC가 측정 신호를 읽는다.

2. MOSFET

- Gate: 스위칭 제어 입력
- Drain / Source: 전류가 흐르는 경로를 형성한다.
- 바디 다이오드는 MOSFET 내부에 형성되는 다이오드다.

3. H-브리지

- MOSFET 4개로 구성하는 기본적인 양방향 구동 회로다.
- 스테퍼 모터의 코일 전류 방향을 바꿀 수 있다.
- 관통 전류를 방지하는 게이트 제어가 필요하다.

4. 앞으로 공부할 내용

- [ ] MOSFET 게이트 드라이버
- [ ] 전류 순환과 감쇠 방식
- [ ] PWM과 전류 제어
- [ ] 마이크로스테핑
- [ ] ESP32 타이머와 실시간 제어
- [ ] 하드웨어 과전류 보호
- [ ] 센서리스 호밍

설계 원칙

- 회로를 검증하기 전에는 모터에 고전력을 공급하지 않는다.
- 과전류 보호와 MOSFET 관통 전류 방지를 고려한다.
- 회로도, 부품 데이터시트, 시험 결과를 함께 기록한다.
- 검증된 사실과 아직 확인하지 못한 가정을 구분한다.
